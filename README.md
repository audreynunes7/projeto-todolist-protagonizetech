# To-Do List - Full Stack

Projeto desenvolvido para o Bootcamp Avanade + Impacta - Protagonize Tech.

##  Tecnologias Utilizadas
- **Front-end:** Angular (TypeScript)
- **Back-end:** .NET Core / Web API (C#)
- **Banco de Dados:** SQL Server

##  Como Executar o Projeto

### Pré-requisitos
- Node.js e Angular CLI
- .NET SDK
- SQL Server

### Passo 1: Back-end
1. Acesse a pasta do back-end pelo terminal.
2. Execute o comando `dotnet restore` e `dotnet run`.

### Passo 2: Front-end
1. Acesse a pasta do front-end pelo terminal
2. Execute `npm install` e aguarde.
3. Execute `ng serve` e aguarde.
4. Acesse `http://localhost:4200` no seu navegador (pode clicar no próprio link que aparece no terminal segurando o Ctrl).
